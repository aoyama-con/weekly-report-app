# 新人OJT週報自動生成システム - 設計ドキュメント

## 概要
B2B向け業務WEBアプリケーションとして、新人社員のOJT週報作成を自動化し、評価の標準化と管理側の読みやすさ向上を実現するシステムの要件定義〜設計ドキュメントです。

## 主要機能フロー

### 週報作成フロー
```
[新入社員]
   ↓ 箇条書き入力
[週報作成画面]
   ↓ 「生成」ボタン → トーン選択
[LLM API] (社内向け/客先向け)
   ↓ 報告書文体に変換
[生成結果表示]
   ↓ 編集（任意）
[提出]
   ↓
[DB保存] (status: submitted)
```

### レビュー・アドバイスフロー
```
[OJT実施者]
   ↓ 週報閲覧
[レビュー入力画面]
   ↓ ルーブリック評価 + コメント
[保存]
   ↓ 自動でアドバイス生成開始
[LLM API] (新人向け/OJT向け)
   ↓
[週報詳細に表示]
   ↓
[新入社員/OJT] アドバイス閲覧
```

## 受け入れ条件（MVP）

以下の条件を全て満たすことでMVPリリース可能:

1. ✅ 箇条書き入力から、社内向け/客先向けの週報が生成できる
2. ✅ 客先向けでは固有名詞・内部事情が自動マスクされ、検出ログが残る
3. ✅ 生成文章はユーザーが編集でき、提出後にレビューが紐づく
4. ✅ 評価が標準ルーブリック（6項目×5段階）で入力でき、AIアドバイスが新人/OJT双方に表示される
5. ✅ 週報一式（本文+評価+アドバイス）がPDF出力でき、日本語が崩れない
6. ✅ 主要操作（生成、提出、レビュー、PDF出力）が監査ログに記録される
7. ✅ 管理者が期間/社員/現場/ステータスでフィルタ検索できる
8. ✅ OJTは自分の担当現場の新人の週報のみ編集できる（RBAC）

## リスクと対策

| リスク | 対策 |
|--------|------|
| **誤生成・品質低下** | 編集可能UI、再生成ボタン、差分表示、テンプレ固定 |
| **情報漏えい（機密流出）** | RBAC、マスキング（正規表現+LLM）、監査ログ、LLM送信データ最小化 |
| **プロンプトインジェクション** | 入力サニタイズ、システムプロンプト固定、出力検査 |
| **運用負荷（管理者疲弊）** | 現場プロフィール最小項目、テンプレ固定、管理画面簡素化 |
| **LLM API障害** | タイムアウト設定、再試行、キュー、障害時の手動入力フォールバック |
