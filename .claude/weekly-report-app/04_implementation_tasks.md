# 実装タスク分解と優先順位

## タスク概要
新人週報自動生成システムのMVP実装を、フェーズごとに分解し、優先順位を付けます。

**実装方針**:
- まず縦割りで「週報作成→生成」の最小機能を実装（Vertical Slice）
- 次に評価・アドバイス機能を追加
- 最後に管理機能・監査ログを整備

## 技術スタック候補（参考）

| 領域 | 候補A | 候補B | 推奨理由 |
|------|-------|-------|----------|
| **フロントエンド** | React + TypeScript | Next.js | Reactはライブラリ豊富、Next.jsはSSR・API Routesで一体化可能 |
| **バックエンド** | Node.js(Express) | Python(FastAPI) | Node.jsはフルスタックJS、PythonはLLM連携ライブラリ豊富 |
| **DB** | PostgreSQL | MySQL | PostgreSQLはJSON型サポート、拡張性高い |
| **LLM** | OpenAI GPT-4o | Claude Sonnet | GPT-4oは速度・コスト優、Claudeは長文・安全性優 |
| **PDF生成** | Puppeteer | wkhtmltopdf | Puppeteerは柔軟なHTML/CSS対応 |
| **認証** | JWT | OAuth2.0 | JWTはシンプル、OAuthは外部ID連携可 |
| **インフラ** | AWS(EC2/RDS/S3) | GCP | AWSは実績豊富、GCPはVertex AI連携容易 |

**MVP推奨スタック**:
- フロント: React + TypeScript + Vite
- バックエンド: Node.js + Express + TypeScript
- DB: PostgreSQL
- LLM: OpenAI GPT-4o（社内向け）、GPT-4o（客先向け）
- PDF: Puppeteer
- インフラ: AWS（EC2 + RDS + S3）
